# KneadIt v1.60.0

Date: 2026-10-09
Tag: v1.60.0

## Summary

Address fields suggest real addresses from Google as you type.

## Highlights

- **Address suggestions** (#1394). The bakery address (setup and Settings), the customer address in the admin, the storefront checkout delivery address and the catering venue address (admin and storefront) suggest addresses from Google Places as you type, limited to the bakery's country. Picking one fills street, city, state and ZIP where those are separate fields, or the full formatted address. Setup's Contact info step gains City, State and ZIP. Typing by hand still works; without a key the fields are plain text boxes.
- **CI** (#1393). Browser Smoke runs without the debug toolbar, like production.

## Database and deployment notes

- **Migrations:** none.
- **Configuration:** `services.google_maps.browser_key` reads `GOOGLE_MAPS_BROWSER_KEY` (already set on production; restricted to `*.getkneadit.app`, Places API (New) and Maps JavaScript API).
- **Content Security Policy:** storefront allows `https://maps.googleapis.com` and `https://maps.gstatic.com` (scripts) and `https://maps.googleapis.com`, `https://places.googleapis.com` (connections).
- **New dependency:** `@googlemaps/js-api-loader` (npm, Google's official loader, bundled by Vite).
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: `/up`, type an address in a bakery's Settings and pick a suggestion, then check Places usage in Google Cloud.
