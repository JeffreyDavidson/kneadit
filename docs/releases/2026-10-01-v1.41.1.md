# KneadIt v1.41.1

Date: 2026-10-01
Tag: v1.41.1

## Summary

Hotfix: platform email campaigns are managed only by the platform and go to bakery owners.

## Changes

- **Platform email campaigns** are managed only in the platform admin panel. The bakery admin no longer has an "Email Campaigns" page. Bakeries keep emailing their own customers with **Customer Campaigns**, which is unchanged.
- **Recipients:** platform campaigns go to bakery owners (each bakery's account email), filtered by the chosen plan segment and deduplicated. They're platform-branded.
- Sending a platform campaign from inside a bakery context is refused.

## Database and deployment notes

- No database migrations.
- Existing rows in `email_campaigns` are kept. They can't be attributed to a bakery, so review them in the platform admin and delete any you don't recognize.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
