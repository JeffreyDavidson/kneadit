# KneadIt v1.58.0

Date: 2026-10-08
Tag: v1.58.0

## Summary

Bakery setup asks for the bakery's time zone.

## Highlights

- **Time zone in setup** (#1384). The Business hours step has a required, searchable time zone choice above the days, pre-selected from the owner's browser (or the bakery's existing non-UTC zone). It saves to the same `timezone` setting that drives "today", order cut-offs and pickup times. Manage Settings uses the same readable list (for example "New York (Eastern Time, UTC-4)"); stored values are unchanged.

## Database and deployment notes

- No new environment variables or dependencies.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: `/up`, a bakery's Settings time zone list, and Nightwatch on the new release.
