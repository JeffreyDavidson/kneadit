# KneadIt v1.52.0

Date: 2026-10-06
Tag: v1.52.0

## Summary

Both admin panels move onto the new KneadIt design system and open in light mode by default, KneadIt's own emails share one branded template, and a set of admin and email bugs are fixed.

## Highlights

- **New look for both admin panels** (#1341, #1342, #1343, #1344). One set of KneadIt colours, Young Serif page titles and Instrument Sans text across the bakery admin and the platform admin. Both now open in **light** mode; people can switch to Dark or Match my device from the user menu. Gold buttons use dark text for readability. The old Honey / Slate / Nord theme picker is gone.
- **Branded KneadIt emails** (#1337, #1338). The verification, welcome, trial, payment and platform-admin emails share one KneadIt template with the logo, a gold button and a fallback link. The five emails that were plain text now also have an HTML version.
- **Order email totals** (#1347). A bakery's customized order emails showed `{order_total}` 100 times too small; the owner's new-order email subject showed `$$`. Both fixed, along with doubled `$` on the Upcoming Orders widget and Customer Directory.
- **Admin pages that didn't work** (#1346). Quick Order now shows its form and creates orders; Printable Menu and Weekly Prep Planner load again.
- **Dashboard widgets** (#1347). Needs Attention no longer crashes when it has items; the platform Revenue Overview, Customer Insights and the announcement banner no longer fail when served from cache; tables no longer show a "0" filter badge; revenue charts follow the light/dark theme.
- **Smaller fixes.** The register page keeps "I agree to the terms" ticked after a form error (#1336); the platform Bakeries table fits the screen (#1346); admin favicons point at real files (#1341); `shell-quote` forced to 1.12 for a security advisory (#1340).
- **For developers.** Browser tests for the owner signup journey and settings persistence run in Browser Smoke (#1345); local email previews at `/mail-previews` (#1339).

## Database and deployment notes

- No database migrations.
- `config/kneadit.php` drops the unused `central_theme` key; no environment change is needed. Old `admin_theme` / `central_theme` setting rows are ignored.
- `public/css/central-admin.css` is removed; the panels' styles come from the Vite build, so the deploy must run `npm run build` as usual.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: sign in to a bakery admin and the platform admin and check they open in light mode with the new look; switch to dark from the user menu; open Quick Order.
