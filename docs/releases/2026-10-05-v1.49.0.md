# KneadIt v1.49.0

Date: 2026-10-05
Tag: v1.49.0

## Summary

A bakery's subdomain is now stored separately from its internal id, so it can differ from the id and be changed. Every bakery link is built from it. This also fixes broken directory, printable menu and QR code links, and the address a new owner is sent to after signing up.

## Highlights

- **Bakery subdomains** (#1326). Until now a bakery's subdomain was its internal id, so it couldn't be changed without renaming the id (its database file, stored files and related records).
  - A new `tenants.subdomain` holds the subdomain. Every bakery link (storefront, admin, help centre, impersonation, billing) uses it.
  - Platform admins can change a bakery's subdomain from the bakery's Edit page ("Change subdomain"), and operators can use `php artisan tenants:change-subdomain {bakery} {subdomain}`. Both use the signup rules (allowed characters, reserved names, not already taken).
  - The old subdomain keeps working: page loads on it are redirected permanently (301) to the new one, with the same path and query. Form submissions aren't redirected, and custom domains are never affected. Absolute signed links on an old subdomain fail their signature after the redirect.
  - New bakeries are unchanged: their subdomain is the one they choose at signup.
- **Directory, printable menu and QR code links** (#1326). These built links from the bakery's first domain record, which for a bare subdomain gave an invalid address such as `http://bakery-on-biscotto`. They now use the verified custom domain or `https://{subdomain}.getkneadit.app`.
- **After signing up** (#1326), a new owner is sent to `https://{subdomain}.getkneadit.app/admin`. Before, the address was built from the platform's own host (`{subdomain}.app.getkneadit.app`).

## Database and deployment notes

- **One central migration**, `2026_10_05_120000_add_subdomain_to_tenants_table`: adds a nullable `tenants.subdomain` in place (the table isn't rebuilt) and fills it from each bakery's existing subdomain record, or its id. Existing bakery addresses don't change at deploy.
- **After deploy (owner approval):** `php artisan tenants:change-subdomain bakery-on-biscotto bakeryonbiscotto` moves Bakery on Biscotto to `bakeryonbiscotto.getkneadit.app`; the hyphenated address then redirects.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
