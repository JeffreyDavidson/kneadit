# KneadIt v1.59.0

Date: 2026-10-08
Tag: v1.59.0

## Summary

Uploaded images load reliably, the contact form keeps the phone number, and the social calendar uses the bakery's own days.

## Highlights

- **Images on the public disk** (#1387, #1391). Product and social post photos uploaded in the admin are now stored on the public disk (they were landing on the private default disk on production and never showed). Every reader of product, blog, store/about, catering, hero, call-to-action and gallery images resolves the URL against the public disk explicitly, so images no longer depend on `FILESYSTEM_DISK`. A dry-run-by-default command `images:copy-private-to-public` exists for any stray files (none on production as of 2026-10-08).
- **Contact form phone** (#1390). The storefront contact form (classic and Biscotto themes) has an optional phone field using the shared phone input; the number is stored in E.164 and shown, with a tap-to-call link, in the admin message list, the message page and the new-message email.
- **Social calendar** (#1388). Posts are grouped by the bakery's local day and month, so an evening post no longer shows on the next day.
- **Storefront menus** (#1389). The Alpine collapse plugin is registered, so the mobile menu, Explore and Account submenus and the contact FAQs animate and stop logging console warnings.
- **Tests** (#1386). The browser smoke order tests use a complete phone number, so Browser Smoke passes again.

## Database and deployment notes

- **Migration:** 1 per bakery: nullable `contact_messages.phone` (column add only, no table rebuild).
- **Before deploying:** confirm a fresh central and tenant backup exists (the backup gate).
- **New dependency:** `@alpinejs/collapse` (npm, bundled by Vite). No new environment variables.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: `/up`, a storefront contact page, a product image on a storefront, and Nightwatch on the new release.
