# KneadIt v1.52.1

Date: 2026-10-06
Tag: v1.52.1

## Summary

A patch release: platform account pages now answer only on the main KneadIt site, and the admin header avatar is visible in dark mode.

## Highlights

- **Platform account pages on the main site only** (#1350). Registration, email verification, password reset and bakery setup now answer only on the central KneadIt domain, the same way billing already does. On a bakery's own address they return "not found". Customer accounts and bakery staff sign-in are separate pages and are unchanged.
- **Header avatar in dark mode** (#1349). The initials avatar in both admin panels has a ring in dark mode so it no longer disappears against the dark header.

## Database and deployment notes

- No database migrations and no configuration changes.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: confirm `https://<bakery>.getkneadit.app/register` returns 404 and `https://app.getkneadit.app/register` still shows the sign-up form.

Release verification is pending. Confirm the release PR checks and Browser Smoke on the release tag before relying on it.
