# KneadIt v1.55.0

Date: 2026-10-07
Tag: v1.55.0

## Summary

Bakery setup gets its own focused page.

## Highlights

- **Setup page redesign** (#1368). Setup no longer shows the admin sidebar: a slim header with the bakery's logo and name and a "Save and finish later" link (signs out; each step is already saved on Continue), a step list on the left that ticks off finished steps, and one card per step with a large heading, the fields and a Continue button. On phones the step list shrinks to one line above the card. Labels are in sentence case. What each step saves, step order and validation are unchanged.

## Database and deployment notes

- **Migrations:** none.
- No new environment variables or configuration changes.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: `/up`, and the setup page on a bakery whose setup isn't complete.
