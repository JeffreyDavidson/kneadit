# KneadIt v1.38.0

Date: 2026-09-27
Tag: v1.38.0

## Summary

Improve Reports Center exports and reporting coverage, while reducing repeated data loading across tenant insights, analytics, financial reports, inventory, scheduling, and order workflows.

## Highlights

- **Reports:** Wire the RFM report into Reports Center and make CSV exports include complete report data, with browser-flow coverage (#1152–#1155).
- **Catering and page structure:** Extract reusable catering inquiry components and view models, share event fields and options, centralize deposit calculation, and simplify order and survey-result views (#1142–#1151).
- **Tenant insights:** Consolidate health and churn reads and centralize platform tenant metrics, preserving independent failure handling and existing alert behavior (#1157–#1160).
- **Performance:** Reduce repeated or unnecessary reads across feature usage, storefront analytics, reviews, signup metrics, weekly digests, financial reports, product trends, reminders, tenant comparisons, content, delivery, inventory, scheduling, catering, orders, Filament widgets, and customer reports (#1161–#1178, #1180–#1182).
- **Inventory and consistency:** Share order ingredient stock adjustments and snapshot seasonal availability dates; improve financial product-sales mapping (#1172, #1179, #1183).
- **Local development and test reliability:** Configure local platform-admin seeding, align browser tests with the local app domain, and isolate Pest configuration from local settings (#1139–#1141).

## Database and deployment notes

- No database migrations are included in this release candidate.
- No special one-off data migration is required. Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including synchronizing the version before configuration caching.
