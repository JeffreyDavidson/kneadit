# KneadIt v1.39.1

Date: 2026-09-30
Tag: v1.39.1

## Summary

Patch release with dependency security updates and a capacity limits table fix.

## Highlights

- **Security updates** (lock files only):
  - `league/commonmark` 2.10.1 → 2.10.3 for GHSA-3q6v-r5mr-hxv8 (High) and GHSA-97jj-33gv-5xf9 (Medium).
  - `axios` 1.19.0 → 1.20.0 for seven advisories against 1.0.0–1.19.0.

  Neither is used on customer-supplied input. `commonmark` renders the repository's help-center Markdown and Laravel Markdown (such as emails); `axios` runs in the browser bundle against the app itself (#1200).
- **Capacity limits table:** weekday limits sort Monday → Sunday, then date-specific limits by date, instead of alphabetically; the "Day / Date" column is the default sort (#1199).

## Database and deployment notes

- No database migrations.
- Run `composer install` and `npm ci` / `npm run build` as part of the normal deploy so the updated lock files take effect.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including synchronizing the version before configuration caching.
