# KneadIt v1.54.0

Date: 2026-10-07
Tag: v1.54.0

## Summary

A tidier bakery setup wizard and the bakery's logo shown at a proper size.

## Highlights

- **Bakery logo** (#1366). The bakery's own logo is sized by height in the admin top bar (with the bakery name beside it) and larger on the sign-in card. The KneadIt wordmark shows only when a bakery has no logo.
- **Setup wizard** (#1366). Each step shows "Step N of 10" with a progress bar instead of the cut-off step header; one centred card with Back/Next/Finish at the bottom; the first step reads "Let's get {bakery} ready" and says setup takes about 5 minutes. What each step saves is unchanged.

## Database and deployment notes

- **Migrations:** none.
- No new environment variables or configuration changes.
- Follow the standard deployment checklist in [Operations](../operations.md#deployment-and-release), including `bin/sync-version` before configuration caching.
- After deploying: `/up`, a bakery admin sign-in (logo size), and the setup wizard on a bakery whose setup isn't complete.
